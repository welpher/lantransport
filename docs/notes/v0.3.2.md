Folders keep their shape when you upload them.

## Added

- **Folder upload on the share page.** Drop a folder on the page, or use the new
  **Choose folder** button, and the files arrive inside folders of the same names
  instead of being flattened into the folder you are looking at. Empty folders
  are recreated too when a folder is dragged. Each path segment is checked with
  the same rules as a file name (`..`, absolute paths, backslashes, dot-names and
  Windows reserved names are refused), the resolved folder must stay inside the
  share even through a symlink, and resume-after-a-drop keeps working per file.
  A folder with more than 2000 files sends the first 2000 and says so.

## Changed

- The two hint lines in the upload dialog are now one tinted info box with a
  heading and a single info icon, instead of two loose paragraphs with a small
  icon each.
- README screenshots of the share page retaken; they still showed the page from
  before the theme switch, the refresh button, Select and the folder download.

## Fixed

- The glyph next to **Drop to upload** was a folder with a downward arrow, which
  reads as *download*. It points up now.
- The **Open** arrow on a *Recent uploads* row answered with a raw `not a folder`
  message once that folder had been deleted or its share removed, in English even
  in a Chinese window. It now opens the nearest folder that still exists, and when
  nothing is left the message follows the window's language.
