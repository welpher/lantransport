A fix release for Windows, plus a little polish.

## Fixed

- **IPv4 was unreachable on Windows in 0.3.0.** The IPv6 change bound `[::]`,
  which is only dual-stack where the platform defaults `IPV6_V6ONLY` to 0 —
  Windows defaults to 1, so the listener accepted IPv6 only and every IPv4 link
  the app printed timed out. The socket is now created explicitly dual-stack,
  with an IPv4 fallback for hosts without IPv6.
- Dual-stack sockets report IPv4 clients as `::ffff:a.b.c.d`; they are unmapped
  before they reach the log, the notification and the rate limiter.
- The tray icon was meant to match the app icon but still used an old glyph.
  Every icon — tray, app, PWA, favicon — is now generated from a single
  `assets/mark.svg`, so they cannot drift apart again.
- Opening a folder from the tray, the Activity tab or the folder list now opens
  it in the file manager and brings that window to the front (it used to reveal
  the folder inside its parent and stay behind).
- Deleting a shared folder and restarting the app brought it back; folder changes
  are saved immediately.
- Uploads from a subfolder landed in the first folder's `uploads/`, and folders
  with spaces or Chinese names failed. They now go into the folder being viewed.
- The share page no longer gains and loses 11 px of width when its scrollbar
  appears.

## Added

- **Activity tab** in the desktop window: the last 50 uploads with size, sender
  and time; the arrow opens the receiving folder.
- **Recursive search**: press Enter in the share page's search box to search the
  folder and everything below it.
- **Automatic upload retries** (1 s, 3 s) that resume from the last byte.
- **Motion pass**: rows stagger in, the upload ends with a green tick, copy
  buttons pop, the live dot breathes and a thin progress line runs across the
  top during refresh or upload. Everything is disabled under
  `prefers-reduced-motion`.
- Tray menu: **Open logs folder**.
- The app writes a log line when it starts, when sharing starts and when it
  stops, so the file exists on a fresh install.

## Changed

- After an upload the list refreshes in place instead of reloading the page.
- README explains why the browser shows "Not secure" and what that means on
  public Wi-Fi.
