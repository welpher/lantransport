Uploads that behave, and a window that closes into the tray.

## Added

- **Upload queue.** Dropping something while another upload is running no longer
  starts a second transfer: it waits its turn, the status line says how many files
  are queued, and the dialog closes only once the whole queue is finished.
- **Cancel.** An ✕ button next to the progress bar stops the transfer, skips the
  rest of the queue and keeps whatever already arrived (the half file can be
  resumed later).
- **Recent uploads survive a restart.** The Activity tab keeps its list in
  `recent.json` next to the settings, so closing the app no longer erases it.
  Entries from an earlier day show the date as well as the time.
- A drop shows up **immediately**: the row and the single
  "Receiving folder trip (1900 files, 14.9 MB)" notification appear with the first
  file, and the row counts up as the rest arrive.

## Changed

- One **folder** drop is one row in Recent uploads, named after the folder and
  showing the file count and total size. Picking **many files** writes one row per
  file, because those files are unrelated; the notification is still a single one.
- Fresh screenshots of the share page and of the desktop window.

## Fixed

- **Stop sharing** did nothing while a big upload was running: every upload
  refresh rebuilt the tray menu on the main thread, and the start/stop commands
  were queued there too. Uploads now only reach the window, the two commands run
  off the main thread, and the status pill says "Stopping…".
- **Starting again right after a stop** said the port was taken. The dual-stack
  listener never asked for `SO_REUSEADDR`, so the TIME_WAIT entries left by the
  uploads blocked it for up to a minute.
- **macOS**: closing the window hid it but left the app in the Dock. Closing now
  leaves only the menu-bar icon, and opening it from the tray brings the Dock
  icon, the menu bar and the focus back.
- A second drop finishing early used to close the dialog and wipe the progress and
  the cancel button of the upload that was still running.
