First release after a month of review fixes — nearly every part of the app changed.

## Fixed

- **Large uploads no longer stall around 2.5 MB.** On macOS/BSD the accepted
  socket inherited `O_NONBLOCK` from the listener, so body reads failed with
  `EAGAIN` mid-transfer; iPhone uploads died with "upload interrupted". Sockets
  are now blocking again and there is an 8 MB regression test.
- **Stored XSS via uploaded file names** (script payloads rendered in the
  listing) — names are escaped everywhere and the audit findings are closed.
- iOS Safari no longer zooms the page when focusing the upload key field
  (16px form controls).
- If sharing cannot start on boot (port busy, permission denied), the window now
  shows a banner and a system notification instead of failing silently.

## Added

- **Sortable listing** by name, size or modified time (ascending/descending).
- **QR code for the upload link** — scan it and the key is pre-filled.
- **Upload retry** with percentage, speed and remaining time.
- **Live share-link refresh**: when the network changes (office → home), the
  addresses and QR code update within 15 seconds; the desktop app pushes them
  to open pages.
- **Port checks**: the settings field validates on blur, and sharing refuses to
  start while the port is taken.

## Changed

- Default port is now **8787** (8000/8080 collide with too many other tools).
  An already saved port is kept as-is.
- Desktop package: the installer is smaller and the release is one draft instead
  of two.

## Notes

- macOS and Windows builds are **unsigned**: on macOS right-click → Open the
  first time, on Windows SmartScreen will warn. Signing is planned.
- Linux: AppImage, `.deb` and `.rpm` are provided.
