The biggest update so far: the web page got a real toolbar, and uploads can now
survive a dropped connection.

## Added

- **ZIP download.** Every folder row has the same Download button as a file, but
  it streams `<folder>.zip` — no wait for a temp file, an exact progress figure,
  and hidden files or symlinks are left out.
- **Select files, download just those.** The new Select button turns rows into
  checkboxes with a running total; the archive contains exactly what you ticked.
- **Resumable uploads.** If the phone loses Wi-Fi mid-upload, retry picks up from
  the last byte instead of starting over.
- **Theme.** Follow the system, or pin light/dark from the header. The window
  title bar follows along.
- **Refresh without reloading.** The toolbar's ↻ re-reads the folder and keeps
  your search term, sort order and scroll position.
- **Sort is remembered** across reloads (`lt_sort` cookie).
- **Add to Home Screen.** The page ships a web manifest and icons; on iOS it
  opens without browser chrome. (Chrome's install prompt needs HTTPS, which a
  plain LAN address cannot offer.)
- **Drop a folder on the window** to share it. Dropping one that is already
  shared tells you so instead of doing nothing.
- **Desktop notification** for every finished upload, with sender and size.
- **IPv6.** The listener is dual-stack, so IPv6-only hotspots work, and IPv6
  addresses appear in the share links.

## Fixed

- Deleting a shared folder and restarting the app brought it back — folder
  changes are now saved immediately.
- The folder list did not refresh when a folder was dropped on the window.
- Uploads from a subfolder landed in the first folder's `uploads/`; they now go
  into the folder being viewed. Folders with spaces or Chinese names also work.
- Select boxes kept a blue focus ring after picking a value.
- The share page gained and lost 11 px of width when its scrollbar appeared.

## Changed

- The header is a full-width sticky bar; the page sticks to the top while you
  scroll and no longer shifts sideways.
- The share page uses the app icon instead of a folder glyph, with a clearer
  size hierarchy.
- The desktop window only scrolls its content area, with a thin scrollbar that
  appears when needed.
- Installer: 4.6 MiB. macOS and Windows builds are still unsigned — right-click
  to open on macOS, expect SmartScreen on Windows.
